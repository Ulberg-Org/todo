  - Mounts without a kit: `sbx run claude ~/project-a ~/shared-libs:ro` mounts the extra directory read-only at the same path. `sbx run claude ~/shared-libs:/workspace/libs:ro` sets a target path. These are documented in the usage page's "Multiple workspaces" section.
