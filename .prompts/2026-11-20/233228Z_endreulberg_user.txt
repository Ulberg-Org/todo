I just want to note something on health and cleanliness factors. You should always strive for least priviliges and zero trust. You should always attempt to use the least memory footprint both from the tools you download, run and the code you write. You should always try to be as performant and simple as possible, meaning stack over heap allocations. IN addition you should always use the least storage and compute footprint as possible both when selecting tehcnologies, setting up local dev, for the cloud and just in general.
